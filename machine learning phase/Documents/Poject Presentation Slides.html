Problem, Dataset & Objective

Dataset Overview
  • Name: Adult (Census Income) Dataset
  • Source: UCI Machine Learning Repository
  • Origin: 1994 United States Census Database
  • Records: 48,842 instances
  • Attributes: 14 predictor features + 1 target
  • Target variable: Income (≤50K or >50K)
  • Missing values: workclass, occupation, native-country
  • Feature types: 5 numerical, 9 categorical
Problem Statement
  • Predict whether an individual's annual income exceeds USD 50,000
  • Binary classification task — two predefined income categories
  • Informed by demographic and occupational census attributes
  • Supports socioeconomic policy, credit risk, and financial planning decisions
Objective of the Analysis
  • Develop and evaluate ML classification models on the dataset
  • Identify attributes that contribute most strongly to income prediction
  • Apply a complete data mining workflow end-to-end
Algorithm Selection
  • Decision Tree (CART) — non-parametric, no distributional assumptions, handles mixed feature types and non-linear interactions
  • Gaussian Naive Bayes — probabilistic, lightweight baseline; assumes conditional feature independence
  • Pairing reveals impact of correlated features on a model that assumes independence vs. one that does not
  • Five train-test splits tested: 50:50, 60:40, 70:30, 80:20, 90:10

Key insight: Correlated features (relationship & marital-status) are expected to limit Naive Bayes precision, while Decision Tree naturally handles feature interactions.

Data Preprocessing & EDA

Preprocessing Steps
  • Missing value handling: Mode imputation applied to workclass (5.73%), occupation (5.75%), native-country (1.75%) — all three categorical columns
  • Outlier detection: IQR method on 5 continuous features; capital-gain (8.3%) and capital-loss (4.7%) flagged
  • Outlier handling: Winsorisation at 99th percentile — reduced capital-gain max from 99,999 → 15,024
  • Encoding: Label encoding for sex and income; one-hot encoding for 6 categorical columns; feature space expanded to 100+ columns
  • Feature selection: Mutual Information scoring — 41 most informative features retained; native-country and race dummies excluded
  • Normalisation: MinMaxScaler on 5 continuous features only; fitted on training partition per split to prevent data leakage
  • Duplicates: 52 exact duplicate rows removed; final dataset: 48,789 records
Key EDA Findings
  • Class imbalance: ≤50K = 76.1%, >50K = 23.9% — addressed via class_weight="balanced" in Decision Tree
  • Top MI features: relationship (0.116), marital-status (0.108), age (0.068), education-num (0.065), occupation (0.052)
  • Correlation with income: education-num (0.33), age (0.23), hours-per-week (0.23), capital-gain (0.22)
  • Skewness: capital-gain = 11.89, capital-loss = 4.57 — extreme right skew; post-winsorisation capital-gain = 4.61
  • High earners profile: age 35–60, hours-per-week 40–60, Married-civ-spouse, Exec-managerial or Prof-specialty
  • Gender gap: Males show notably higher proportion of >50K earners than females

Conclusion, Recommendation & Limitation

Summary of Main Findings
  • Decision Tree outperformed Naive Bayes on Accuracy, Precision, F1, and AUC across all five splits
  • Naive Bayes maintained higher Recall — a structural result of violating the independence assumption with correlated features (relationship, marital-status, sex)
  • Most significant predictors: marital-status (Married-civ-spouse), relationship, capital-gain, education-num, age
  • Target class imbalance (76:24) managed via class_weight="balanced" — resampling not required
Meaning of the Result
  • Income is strongly tied to marital and occupational status — confirming known socioeconomic patterns
  • Education level (0.33 correlation) is the single strongest numerical predictor
  • Investment returns (capital-gain) are concentrated among a small high-earning subset
Practical Recommendation
  • Governments: Target interventions (education access, job training) at identified low-income demographic segments
  • Financial institutions: Use Decision Tree's transparent logic for credit risk assessment — explainable to clients
  • Fairness check required before deployment — sex and race showed disparate representation in >50K class
Strength of the Analysis
  • Comprehensive preprocessing pipeline with every step justified from EDA findings
  • Systematic evaluation across 5 train-test splits — more reliable than single-split evaluation
  • Stratified sampling at every split preserves realistic class proportions
  • Mutual Information feature selection avoids linear-only assumptions of correlation
  • Decision Tree provides interpretable, auditable predictions
Limitation of the Analysis
  • Dataset from 1994 — income patterns have changed considerably; findings may not generalise to today
  • Class imbalance remains a structural challenge; SMOTE or other resampling not applied
  • A single Decision Tree is sensitive to training data changes; ensemble methods would be more stable
  • Naive Bayes independence assumption violated by correlated categorical features
Future Improvement
  • Apply ensemble methods — Random Forest or Gradient Boosting — for improved accuracy and stability
  • Implement SMOTE resampling to address class imbalance more directly
  • Evaluate on more recent census data to test contemporary validity
  • Engineer polynomial interaction terms (e.g., age × education) for richer feature space
